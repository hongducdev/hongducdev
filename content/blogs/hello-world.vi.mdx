# Chào mừng đến với blog tiếp theo của mình!

Xin chào mọi người! Đây là bài viết đầu tiên trên blog cá nhân mà tôi vừa xây dựng bằng **Next.js** và **MDX**.

## Tại sao tôi tạo blog này?

Có nhiều lý do khiến tôi quyết định tạo một blog cá nhân:

-   **Chia sẻ kiến thức**: Trong quá trình học và làm việc, tôi đã tích lũy được nhiều kinh nghiệm và muốn chia sẻ với cộng đồng
-   **Ghi chép học tập**: Blog sẽ là nơi tôi ghi lại những gì đã học, những vấn đề đã giải quyết
-   **Kết nối cộng đồng**: Hy vọng thông qua blog, tôi có thể kết nối với nhiều developer khác

## Công nghệ được sử dụng

Blog này được xây dựng với các công nghệ hiện đại:

1. **Next.js 15** - React framework mạnh mẽ
2. **MDX** - Markdown với khả năng embed React components
3. **Tailwind CSS** - Utility-first CSS framework
4. **TypeScript** - Type safety cho JavaScript
5. **View Transition API** - Smooth transitions giữa các trang

### Code example

Đây là ví dụ về một React component đơn giản:

```javascript
const Welcome = ({ name }) => {
    return (
```

-   Những công cụ hữu ích cho developers
-   Và nhiều chủ đề thú vị khác!
